Removals Sheet Connection

This connection is separate from Follow-ups. It reads and writes the Removals Tracker tab through a secure Netlify server function.

Connection details are configured in Netlify, not in this browser.

Set REMOVALS_SCRIPT_URL and REMOVALS_TOKEN under Site configuration → Environment variables. This keeps your private token out of browser storage.

  1. Deploy Removals_Workspace.gs in Google Apps Script as a Web App, executing as you, with access set to Anyone.
  2. Set the same private token in the Apps Script TOKEN constant and Netlify's REMOVALS_TOKEN variable.
  3. Set the deployment's /exec URL as Netlify's REMOVALS_SCRIPT_URL.
  4. Redeploy the site with Netlify Functions enabled, then test below.
No token is stored in this browser.
